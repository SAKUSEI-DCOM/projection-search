無料版Octoparse CSV取込（v18）

Octoparse無料版で手動エクスポートしたCSVを、サイトの告知候補に変換するための手順です。X投稿の自動取得機能ではありません。

  1. WindowsのOctoparseで、利用条件を確認した上で投稿データをCSVにエクスポート
  2. 列名を post_url,post_text,published_at,author にする
  3. 投稿日時は 2026-11-12T20:00:00+09:00 のようにタイムゾーン付きにする
  4. サイトフォルダで以下のコマンドを実行
python scripts/import_octoparse.py export.csv
python scripts/auto_publish.py

更新された candidates.json と schedules.json をGitHubにアップロードしてください。日付・ライバー照合・告知文の条件を満たした予定だけが「要確認」で登録されます。

画像付き投稿の画像収集や、Octoparseの自動実行は行いません。X投稿取得の可否や利用規約を確認してください。
